**最新消息 News**
`id, 標題, 封面圖(可選), 內容, 發布日期, 狀態`

**商品 Product**
`id, 名稱, 分類id, 圖片, SKU, 價格, 規格說明, 庫存數量`

**商品分類 ProductCategory**
`id, 名稱, 排序`

**購物車 / 訂單 Cart / Order**
`Cart: 會員id或訪客session, 項目(商品id, 數量)`
`Order: id, 會員id, 項目明細, 小計, 運費(如有), 總額, 付款狀態, 金流交易編號, 建立時間`

**會員 Member**
`id, 姓名, Email(登入帳號), 手機, 密碼(雜湊), 註冊時間`
→ **您要接的 LINE Login**，通常做法是幫 Member 表加 `line_user_id` 欄位，登入時走 LINE OAuth 拿到使用者 ID 後對應既有帳號，或首次登入自動建立會員資料。這塊不需要動到密碼欄位邏輯，是獨立的登入管道，之後可以跟您已經在寫的部分直接對接。
