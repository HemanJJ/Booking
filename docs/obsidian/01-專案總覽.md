# 專案總覽

## 背景

原網站 https://difly.pos-gpt.com/ 無法存取原始碼與主機，工程師離職。依「重建規格書」從零重做一套複合式運動場館系統。

## 兩個系統

| 系統 | 用途 | 網址 | 狀態 |
|------|------|------|------|
| **球場預約**（difly-booking） | 訂場地（迪飛太平，7 面場） | difly-booking.vercel.app | ✅ 可營業 |
| **租拍**（smartlocker） | 智慧拍櫃租借（5 家分店） | smartlocker-alpha.vercel.app | ✅ 5 店＋分店報表 |

兩者**共用同一個 LINE 官方帳號**與 **LINE Login channel `1660947211`**，LINE 身分一致。

## MVP 範圍（已做）

- 前台：首頁、場館/場地列表、場地詳情、訂位、查閱場地（週表）、我的訂位
- 會員：Email/密碼註冊登入 + LINE 登入（含 LIFF）
- 訂位：30 分鐘單位、防重疊、取消
- 價位：尖峰/離峰、國定假日、時長折扣
- 後台：場館/場地/價位/折扣/訂位/會員/報表
- 部署：Vercel + Neon + GitHub

## 營業規則（現行）

- 營業時間：**08:00 – 00:00**（24 小時功能保留，可後台改回）
- 尖峰/離峰：見 [[05-價位規則]]
- 租拍預設租金：NT$50/次（待改實際價）
