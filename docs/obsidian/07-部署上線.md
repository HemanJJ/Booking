# 部署上線

## 平台分工

| 平台 | 角色 |
|------|------|
| **GitHub** | 存程式碼（`HemanJJ/Booking`） |
| **Vercel** | 跑網站（difly-booking / smartlocker） |
| **Neon** | 雲端 PostgreSQL |

GitHub 與 Vercel **不是二選一**：GitHub 存碼、Vercel 跑站。GitHub Pages 只能放靜態網頁，跑不動 Next.js＋資料庫，所以要用 Vercel。

## 部署方式

- **CLI**（我用）：`vercel --prod`，先 `vercel login`（一次性授權）。
- **GitHub 匯入**：改程式 push → 自動部署（需在 Vercel 設 Production Branch）。

## Vercel 環境變數（difly-booking）

```
DATABASE_URL          = Neon Pooled connection string
SESSION_SECRET        = 長隨機字串
LINE_CHANNEL_ID       = 1660947211
LINE_CHANNEL_SECRET   = Login channel secret
LINE_CALLBACK_URL     = https://difly-booking.vercel.app/api/auth/line/callback
NEXT_PUBLIC_LIFF_ID   = 1660947211-e5z12ax6
LINE_MESSAGING_ACCESS_TOKEN = Bot access token
LINE_ADMIN_USER_ID    = 你的 LINE userId
ADMIN_EMAIL / ADMIN_PASSWORD
```

## 部署流程（新環境）

1. Neon 建 DB → 複製 Pooled connection string。
2. 本地 `DATABASE_URL=… npx prisma db push` + `db seed`。
3. Vercel Import repo → 設環境變數 → Deploy。
4. LINE 後台改 Callback URL / webhook URL / LIFF Endpoint。
