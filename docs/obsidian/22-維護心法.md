# 維護心法（vibe coding 老闆版）

> 做中學、vibe coding 的維護課重點。**背 3 個概念＋1 個動作，三合一就安心。**
> 搭配：[[21-營運晴雨表]]（速查）、`code/🩺 一鍵健康檢查.command`（雙擊檢查）。

---

## 一、git / commit / push / deploy 是「4 個不同的動作」

```
git add      = 挑照片
git commit   = 拍照存檔（本機時光機，可回上一版）
git push     = 上傳 GitHub（雲端保險箱，Mac 壞了程式還在）
./deploy.sh  = 發佈到 Vercel（客人看到新版）
```

- **commit + push = 備份你的程式**；**deploy = 讓客人看到新版**。兩件事！
- 改完程式 4 步都要做（可交給 AI 或 script 一次搞定）。
- ⚠️ Vercel 不會自動「看」你 Mac 的檔案——不部署，線上永遠是舊版（今天修的 404 就是實例）。

## 二、三合一哪些自動、哪些手動

| 層 | 狀態 | 要注意 |
|----|------|--------|
| Vercel 跑站 | ✅ 自動 | UptimeRobot 監控，掛了 Email |
| Neon 存資料 | ✅ 自動 | 每日自動快照（PITR） |
| 每週備份 | ✅ 自動 | 週日 03:30 → iCloud，偶爾瞄 log |
| **LINE 通知** | ⚠️ 自動但**額度會用完** | 每月 200 則；用完靜默停發（非斷線） |
| **OpenRouter** | ⚠️ 自動但**錢會花完** | 儲值 $30；沒錢識圖失效 |
| 改程式 | 🔧 手動 | git 4 步 ＋ deploy |
| 補貨 / 看報表 / 清 demo | 🔧 手動 | 日常經營 |

## 三、一鍵健康檢查（補忘性的實體工具）

- `code/🩺 一鍵健康檢查.command` — 雙擊 30 秒檢查：兩站 health / LINE 額度 / OpenRouter 餘額 / 備份 log / 3 repo 同步。
- **紅字 ❌ = 要處理（附解法）；綠字 ✅ = 放心。**
- 每週日 03:35 自動跑（com.defi.weekly-check）＋通知（見下）。

## 四、OpenRouter 儲值提醒（每週自動）

- 每週日 03:35 launchd 跑 `🩺 一鍵健康檢查.command`（headless 版），餘額 < $1 或 LINE 額度用完 → 彈 macOS 通知提醒。
- 手動：雙擊 🩺 一鍵健康檢查.command。
- 儲值：openrouter.ai → Credits。

## 五、安心 5 條

1. **Mac 只是工具**——壞了客人照常（生意在雲端）。
2. **掛了先開網站確認**（/api/health），別急。
3. **UptimeRobot down 信常常誤報**（冷啟動）。
4. **紙本接單是最後保險**（人工接單範本.csv）。
5. **不知道就雙擊 🩺 一鍵健康檢查**，紅字就是待辦。
