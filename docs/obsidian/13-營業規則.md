# 營業規則（取消 / no-show / 付款）

## 取消規則

| 情境 | 處理 |
|------|------|
| 開打前 **24 小時以上**取消 | 全額退（免費取消） |
| 開打前 **24 小時內**取消 | 收**訂單金額 10%** 手續費（退 90%） |
| no-show（沒取消、沒到場） | 不退費，視同已使用 |
| 場館因素（颱風/停電等） | 場館主動取消，全額退 |

## no-show 累計停權

- 累計 **3 次** no-show → **永久停權**（不能預約）。
- 管理員可**人工解除**停權（後台「解鎖」按鈕；解除時未到次數歸零重新計算）。
- ✅ **已自動化（2026-08-22）**：訂位結束＋6 小時寬限期仍未標記「已到場」→ 系統自動判 no-show（cron 每小時）；後台訂位列表可人工標「已到場 / 未到 / 清除」；會員管理顯示未到次數；達 3 次自動停權並 LINE 通知店家。停權會員前台/代客下單都不能再預約。

## 付款

| 管道 | 方式 | 狀態 |
|------|------|------|
| 線上 | **LINE Pay**（網站直接付） | 待申請 LINE Pay 商家＋寫程式 |
| 實體櫃台 | **雷門 POS** | 獨立，與網站不串 |

## 金流待辦

- [ ] 申請 LINE Pay 商家帳號（https://pay.line.me ，需公司行號）
- [ ] 串 LINE Pay v3 web 付款：訂位 → 付款 → 付款成功才「已確認」
- [ ] 付款完成才能算「已確認」，未付款訂位自動逾期釋放
- [x] 後台加「解鎖停權會員」按鈕（已存在）
- [x] no-show 自動判定＋3 次自動停權（2026-08-22 完成）
