## 三、新 Mac 復原開發環境（約 1~2 小時）

```bash
# 1. 裝工具
#    Node.js（含 npm）、Python3、Git、Ollama

# 2. 拉程式碼
cd ~/Desktop/projects/code
git clone https://github.com/HemanJJ/Booking.git booking
git clone https://github.com/HemanJJ/smartlocker.git smartlocker
git clone https://github.com/HemanJJ/stringing.git stringing
git clone https://github.com/HemanJJ/badminton_mkt.git badminton_mkt

# 3. 填 .env（金鑰從各雲端後台拿，見下）
#    booking/.env           → DATABASE_URL(Neon)、SESSION_SECRET、LINE_*
#    smartlocker/web/.env   → DATABASE_URL、LINE_CHANNEL_ACCESS_TOKEN、STAFF_LINE_USER_ID

# 4. 安裝＋啟動
cd booking && npm install && npx prisma generate && npm run dev
```

## 四、金鑰去哪拿（都不是唯一的，雲端拿得到）

| 金鑰 | 去哪拿 |
|------|--------|
| `DATABASE_URL`（Neon） | console.neon.tech → 專案 → Connection Details |
| `LINE_CHANNEL_*` | developers.line.biz → channel 設定 |
| `LINE_MESSAGING_ACCESS_TOKEN` | developers.line.biz → Messaging API → 重新發行 |
| Vercel 部署 token | vercel.com/account/tokens → 新建 |
| `ADMIN_PASSWORD` / `SESSION_SECRET` | Vercel 專案 → Settings → Environment Variables（在雲端，不丟） |

## 五、本機會丟、要主動備份的（資料庫備份已自動化，見下）

| 項目 | 現況 | 建議 |
