# 技術棧與架構

## 技術棧

| 層 | 工具 |
|----|------|
| 框架 | Next.js 16（App Router + TypeScript + Turbopack） |
| 樣式 | Tailwind CSS v4 |
| ORM | Prisma 7（`prisma-client` generator + Query Compiler） |
| 資料庫 | 本地 SQLite／生產 Neon PostgreSQL（driver adapter 自動切換） |
| 認證 | jose（JWT session）、bcryptjs（密碼雜湊） |
| LINE | LINE Login（OAuth 2.1/OIDC）+ LIFF + Messaging API |

## 架構圖（文字版）

```
客人（手機/電腦）
      │ 開網址 / 點 Rich Menu
      ▼
  Vercel（difly-booking.vercel.app，跑 Next.js）
      │                        │
      │ 讀寫資料               │ LINE 登入
      ▼                        ▼
  Neon（PostgreSQL，永久存）   LINE 官方（回傳身分）

GitHub（存程式碼）──push──▶ Vercel 自動/手動重新部署
```

## 兩套系統的關係

- **程式分開**（球場預約是純網站、租拍有硬體/RS-485/kiosk，本質不同）
- **共用**：LINE Login channel、LINE 官方帳號（Rich Menu 分流）
- 資料庫各用各的 Neon

## 資料庫切換機制（重要）

`src/lib/prisma.ts` 依 `DATABASE_URL` 開頭自動選 adapter：
- `file:` → SQLite（本地開發）
- `postgres` → Neon driver adapter（生產）

Schema 有兩份：`prisma/schema.prisma`（SQLite）與 `prisma/schema.postgres.prisma`（PostgreSQL），改模型時要**兩份同步**。
