# 穿線服務（新專案）

> 羽拍穿線服務的管理系統，獨立於球場預約與租拍。完整交接文件：`/Users/defi/Desktop/projects/code/stringing/HANDOFF.md`

## 一句話

客人拍線斷了 → 到店 kiosk 選線種＋磅數 → 印貼紙貼拍 → 放智慧格口 → 員工取走穿線 → 穿好送回 → 客人付款 → LINE 通知取件 → 掃碼開格取拍。

## 流程（7 步，含付款）

1. 客人交拍：kiosk 選線種＋磅數 → 印 4×3cm 標籤（無 QR，見「列印」段）→ 開空格放拍（待收件）
2. LINE 通知員工新單
3. 員工取件（手機後台開格）→ 格釋放（穿線中）
4. 穿好送回：開「新空格」放拍（待取件）
5. 客人付款（臨櫃/Line Pay/匯款）→ 員工標「已付款」
6. LINE 通知客人取件（**付款後才發**）
7. 客人掃碼開格取拍（已完成）

**核心**：格子是流動的（交拍格 ≠ 取件格），動態分配。

## 列印（中文解法，已定稿）

> ⚠️ **這台 GP-3120TN 的坑**：TSPL 原生為**單字節字型 FONT 0~8**（無內建中文字）、**不吃 BITMAP 指令**（實測最小方塊也無反應）。所以 raw TSPL 印中文＝亂碼/空白，**不可行**。
>
> ✅ **可行解法＝Seagull 驅動印中文**（kiosk 已裝 Seagull 驅動，用 Windows 中文字型「微軟正黑」渲染再送印表機）：
> - 腳本：`code/smartlocker/web/scripts/print-label.ps1`
> - 用 `System.Drawing.Printing.PrintDocument` 畫４行（**線種+色 / 磅數+店名英文 / 金額+店名中文 / 取件號**），紙張用驅動內建 `40 mm x 30 mm`（不是自訂，否則字會轉 90°＋溢頁）
> - `$` 坑：PowerShell 字串 `"NT$250"` 的 `$2` 會被當變數展開成空字串，**要用單引號 `'NT$250'`**
> - **換文字＝改腳本參數** `店名/店名英文/線種/磅數/金額/取件號` 再跑一次（這就是你的「editor」，不需 GUI）
> - 繁體全覆蓋：用微軟正黑，`太平永成店`/`長壽店`(長/壽) 任何店名都印得出
>
> **✅ 自動帶（接訂單資料，已做＋已驗證 2026-08-23）**：
> - `print-label.ps1` 支援 `-ConfigFile <json>`（讀 JSON 欄位 `store/storeEn/line1..line4/slot/note/printer`），供程式安全傳中文/`$`；用 `System.Drawing.PrintDocument` 直接印（**無列印對話框、背景列印**）
> - **kiosk-print-poller.ps1**（**PowerShell 版，kiosk 無 node 可跑**）：輪詢 `/api/print-jobs?status=pending` → 用 `job.label`（`model`+`color`→線種、`tension`→磅數、`price`→金額、`pickupCode`→取件號、`slotNo`→格號、`note`→註記）自動組 4 行 → 寫暫存 JSON → 呼叫 `print-label.ps1 -ConfigFile` → 開格 → 回報完成；`-Once`＝單步
> - **標籤最終版面（4×3cm 驅動內建 `40 mm x 30 mm`）**：`線種+色 [note註記]` / `磅數  Pai store` / `金額  太平永成店` / `取件號 924588  格 N`；note 限 5 字、格號在取件號右
> - **常駐**：kiosk 用 `schtasks` 建「KioskPrintPoller」排程任務（onlogon），跑 `launch-poller.cmd` → 輪詢導向 `poller.log`；每 3 秒輪詢、有新綁定單就自動印（背景）
> - 店名從環境變數 `STORE`/`STORE_EN` 帶入（每店 kiosk 各設自己的）；`PRINTER` 指定印表機
> - ⚠️ **UTF8 坑（重要）**：PowerShell `Invoke-RestMethod` 抓 API 把中文（如 color「白」）**誤解碼成亂碼（ç½）**。**必須用 `HttpWebRequest` + `StreamReader(UTF8)` 讀流**解碼，否則標籤中文色會爛掉。
> - ⚠️ 印表機對話框：`PrintDocument.Print()` 是**程式化直接列印（背景、無對話框）**；若見到對話框是驅動「顯示列印對話框」設定，關掉即可。

## 下單頁：品牌分組、一框無滑（2026-08-24 改版）

`/order`（kiosk 下單）改成 **4 屏 drill-down**，每屏一框、大熱區、**無 scroll**（照打樣 `kiosk-mockup.html`）：

1. **選品牌**：全部 / AL / YOUNG / BG（依 `strings.brand` 動態分組，48+ 加品牌就多一個 chip）
2. **選線種**：該品牌 grid（型號＋線徑/特性＋價格，3–4 欄）
3. **選磅數＋顏色**：大 −/＋ stepper（上限 `max_tension` clamp）＋ 顏色 chips（綁線種）
4. **確認訂單**：訂單卡＋選填備註＋確認下單

- **底**：強制淺色 `#f4f6f8`（照打樣；避免系統深色模式下「深底＋深字」對比差）。
- **保留**：LINE 綁定輪詢、60 秒未綁定作廢、綁定後 4 秒自動返回、結果畫面（取件碼／放進第N格／QR）。
- 打樣：`shop.dearfly.com.tw/kiosk-mockup.html`（已加「🏠 主選單」回首頁，之前會迷路）。

## 語音系統（已做＋定稿 2026-08-24）

> kiosk 語音 MVP（台灣繁中「美佳」TTS），`web/public/kiosk-voice/*.wav`＋`mapping.md`＋`index.html`（demo）。
> 網頁用 `<audio>`（`/kiosk-voice/`）→ **任何裝置可播**；kiosk 另用 `SoundPlayer`（本機 wav）。⚠️ Chrome 擋「沒互動前自動播」。

**4 層、優先級**：① 歡迎/行銷（閒置）→ ② 引導（卡點）→ ③ 報幕（事件）→ ④ 警告（最高）。

**正確觸發時機**：
| 語音 | 時機 |
|---|---|
| `guide-step1/2/3` | 下單頁 步驟變動（選線種/磅數/確認）|
| `anon-bind` | **網頁下單成功時**（還未綁定）→「請掃 QR 加好友綁定」|
| `anon-order` | **網頁綁定完成時**（才配櫃號）→「請依櫃號，將球拍放入櫃中」|
| `warn-close/notclosed/anomaly` | 盒門異常（待接門狀態回報 A0/D2）→ **最高優先** |
| `welcome/marketing` | kiosk 閒置輪播 |

⚠️ 用詞慣例：「**格口**」對外/語音一律用「**櫃門**」（見記憶）。
