# 穿線服務（新專案）

> 羽拍穿線服務的管理系統，獨立於球場預約與租拍。完整交接文件：`/Users/defi/Desktop/projects/code/stringing/HANDOFF.md`

## 一句話

客人拍線斷了 → 到店 kiosk 選線種＋磅數 → 印貼紙貼拍 → 放智慧格口 → 員工取走穿線 → 穿好送回 → 客人付款 → LINE 通知取件 → 掃碼開格取拍。

## 流程（7 步，含付款）

1. 客人交拍：kiosk 選線種＋磅數 → 印 2×3" 貼紙(QR) → 開空格放拍（待收件）
2. LINE 通知員工新單
3. 員工取件（手機後台開格）→ 格釋放（穿線中）
4. 穿好送回：開「新空格」放拍（待取件）
5. 客人付款（臨櫃/Line Pay/匯款）→ 員工標「已付款」
6. LINE 通知客人取件（**付款後才發**）
7. 客人掃碼開格取拍（已完成）

**核心**：格子是流動的（交拍格 ≠ 取件格），動態分配。

## 硬體

- kiosk 主機：Win10（HJS，i7/8G/256G）
- 印表機：**GoDex EZ120**（203dpi，USB，可印 QR，Win10 驅動）
- 標籤：2×3 吋熱感
- 鎖控板：RS-485（現有）

## 架構

- 雲端（Vercel+Neon）：訂單、員工手機後台、LINE 通知、kiosk 網頁
- 本地 kiosk（Win10）：列印＋格口控制（輪詢雲端指令）

## 訂單狀態機

`待收件 → 穿線中 → 待取件 → 已完成`（＋付款旗標）

## 估時

約 **5–9 工作天**；最大變數在硬體（GoDex 列印對位、RS-485 格口整合）。
