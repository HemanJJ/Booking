# 運動商城・進銷存・配貨（2026-08-21 建立）

> smartlocker 從「穿線拍櫃」升級成「**無人場館＋總倉盤商**」的完整系統。
> 商業模式（與老闆確認）：**你是總倉（盤商）→ 真加盟店開張才建立店家 → kiosk 賣貨 → 總倉配貨到店**。

## 一句話架構

```
你＝總倉（商品主檔/訂價/談進價/789折） → 配貨 → 店家 kiosk（自己的庫存） → 客人
後台＝遙控器：🏟️ 分店切換（現在只有「太平總店（總倉）」，真加盟開張才加）
```

## 新功能清單（全部已上線）

| 功能 | 位置 | 說明 |
|------|------|------|
| 商品目錄 | `/store`（kiosk 卡）| 王清標 15 項 × 各 100（總倉）＋各 10（測試加盟店）|
| 進銷存 | 後台 📦庫存 / 📥進貨 / 🔢盤點 / 📊報表 | 進貨單→入庫、盤點、庫存成本/毛利/低庫存/快過期 |
| 量價階梯 | 後台 庫存→量價階梯 | 滿量打折（%或單價），批次套用（全部/分類/單一）|
| **配貨** | 後台 📤配貨 | 總倉→店家 庫存移動＋紀錄 |
| **自動補貨** | 後台 📤配貨→需求單 | 安全存量→缺貨→需求單→配貨草稿→人工審核→核准配送＋LINE 通知 |
| 分店切換 | 後台 各頁頂部 🏟️ | 選哪家店看哪家的貨（venue_id 分店隔離）|
| LINE 通知 | 低庫存＋配貨核准 | 推給 admin＋業者 兩顆 ID（STAFF_LINE_USER_ID 逗號分隔）|
| 後台認證 | `/admin/login`＋🔑改密碼 | 密碼存 DB（admin_credentials），後台可自改 |

## 資料模型（Neon，與 booking 共用庫）

- `inventory`：商品（venue_id＋sku 唯一，**各店各自有貨**、cost_price 談的進價、min_qty 安全存量）
- `price_tiers`：量價階梯（sku, min_qty, percent 或 unit_price）
- `purchase_orders`／`purchase_items`：進貨單
- `stocktakes`／`stocktake_items`：盤點
- `transfers`／`transfer_items`：配貨單（**status: draft→approved→配送**）
- `suppliers`：供應商（line_id 預留一鍵轉單窗口）
- `sale_orders`：販售訂單（**Phase 2 金流才用**）

## 自動補貨流程（老闆設計）

```
① 安全存量（後台人工調）＝計算基礎
② 庫存 ≤ 安全 → 缺貨
③ 需求單：建議補 = 安全×2 − 庫存
④ 一鍵轉配貨草稿（不動庫存）
⑤ 人工審核：核准/退回/改數量
⑥ 核准 → 庫存移動＋LINE「完成配送」
```

## 📖 使用教材（白話教學，可印給員工）

> 完整版另存：`code/smartlocker/docs/販售庫存使用教材.md`。以下同文收錄，供 RAG 檢索。

### 一、這個模組在管什麼
進貨 → 上架 → 販售 → 盤點 → 補貨。庫存太低會 **LINE 通知補貨**。

### 二、欄位名詞
| 欄位 | 白話 | 範例 |
|---|---|---|
| SKU | 商品編號（唯一、不可重複） | `DEFI-BALL-12` |
| 名稱 | 商品名 | 迪飛比賽球（12入） |
| 分類 | badminton 羽球 / ramen 泡麵 / other 其他 | badminton |
| 售價 price | 賣給客人的價 | 300 |
| 進價 costPrice | 進貨成本 | 200 |
| 庫存 qty | 現在剩幾個 | 48 |
| 安全存量 minQty | 低於此數→LINE 提醒補貨（0=不提醒） | 20 |
| 狀態 | 上架中（客人看得到）／下架（看不到） | 上架中 |

### 三、從哪進去
後台首頁 → 📦 販售庫存；上方分頁：穿線／庫存／配貨／進貨／盤點／報表／供應商；右上切分店（各店庫存分開算）。

### 四、建基本資料（照順序 3 步）
1. **建供應商**（必先做，進貨單要選它）。
2. **建商品**（三選一）：
   - 最快＝進貨單收貨自動建檔；次快＝配貨核准自動建；最慢＝庫存頁「＋新增」手動建。
3. （可選）**量價階梯**＝批發折扣（滿50件8折…，可批次套用全部/分類/單一）。

### 五、日常標準流程
- **進貨**：開進貨單 → 收貨入庫 → 庫存＋、更新成本。
- **配貨**：總倉→店家（草稿→核准才動庫存，LINE 通知完成配送）。
- **販售**：客人買 → 系統自動扣庫存。
- **盤點**：每週實際數 → 輸入實際數量 → 校正。
- **補貨**：庫存 ≤ 安全存量 → LINE 自動推播提醒開進貨單。
- **報表**：庫存總值、潛在利潤、低庫存清單、14 天快過期清單。

### 六、快速建檔三撇步
1. 進貨收貨＝自動建商品（最省事）。2. 量價階梯批次套用（一次設整類/全部）。3. SKU 命名有規則（`DEFI-BALL-12`）。

### 七、常見問題
- **下架 ≠ 刪除**：改成「下架」狀態即可，歷史不消失。
- **庫存對不上**：多半漏按「收貨入庫」或漏盤點。
- **切錯分店**：右上角分店要選對（進貨/盤點/配貨以分店為單位）。
- **安全存量填 0**：代表不啟動低庫存提醒。
