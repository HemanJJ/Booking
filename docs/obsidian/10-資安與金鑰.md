# 資安與金鑰

> ⚠️ 這份筆記可能同步到雲端（Obsidian sync / iCloud），**請勿再複製金鑰明文**。金鑰一律存在 `.env`（本地）與 Vercel 環境變數。

## 帳號

| 用途 | 帳號 |
|------|------|
| 球場後台 | `admin@difly.tw`（密碼在 .env 的 `ADMIN_PASSWORD`） |
| 一般會員 | `demo@difly.tw` / `demo1234` |

## 金鑰位置（不在此存明文）

| 金鑰 | 存放位置 |
|------|---------|
| Neon 連線字串 | `.env` 的 `DATABASE_URL` / Vercel |
| LINE Login secret | `.env` 的 `LINE_CHANNEL_SECRET` / Vercel |
| LINE Bot access token | `.env` 的 `LINE_MESSAGING_ACCESS_TOKEN` / Vercel |
| LINE 你的 userId | `.env` 的 `LINE_ADMIN_USER_ID` / Vercel |
| Session secret | `.env` 的 `SESSION_SECRET` / Vercel |

## ⚠️ 待 rotate 清單（正式營運前必做）

因為金鑰曾在對話中曝光，上線前請全數重發：

- [ ] LINE Login channel secret（Developers Console → Basic settings → Issue）
- [ ] LINE Bot channel access token（Messaging API → Issue）
- [ ] Neon 資料庫密碼（Neon console → 重設密碼）
- [ ] 後台管理員密碼（登入後「修改密碼」）
- [ ] `SESSION_SECRET` 換新

## 其他注意

- 確認 GitHub repo 是 **Private**（對話備份含敏感資訊）。
- smartlocker 的 `web/.env.example` 曾誤提交真實 secret，要檢查並清理。
