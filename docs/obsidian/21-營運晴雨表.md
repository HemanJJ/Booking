## 二、晴雨表：發生狀況 → 查哪層 → 怎麼排除

### A. 客人說「網站打不開」
```
① 你手機開 https://dearfly.com.tw 試試
   ├─ 你開得開 → 客人網路問題，叫他重整
   └─ 你也開不開 → 下一步
② 開 https://dearfly.com.tw/api/health
   ├─ 200 {"ok":true} → 網站好的，可能 DNS 暫掛 → 等 10 分鐘再看
   └─ 500/打不開 → Vercel 或 Neon 掛 → vercelstatus.com + console.neon.tech
③ 真掛了：Vercel 後台看錯誤 → 回報給 AI（貼錯誤訊息）
```

### B. 網站開得開，但訂位/下單失敗
```
① /api/health：200 → 程式 bug（截圖貼 AI）；500 → Neon 掛
② 應急：紙本/Excel 接單（範本：booking/docs/人工接單範本.csv）
   修好後 → 後台 /admin/import 批次匯入
```

### C. LINE 沒通知（老闆最常問）
```
① 先查額度：
   curl -H "Authorization: Bearer $LINE_MESSAGING_ACCESS_TOKEN" \
     https://api.line.me/v2/bot/message/quota/consumption
   ├─ 200/200 → 免費額度用完 → 等下月 1 日重置 或 升級付費方案
   └─ 未滿 → 檢查 webhook 是否啟用 / 是否誤按 Reissue
② ⚠️ token 別按 Reissue（按了要同步 Vercel 兩站＋deploy）
```

> ⚠️ **2026-08-23 現況：LINE 額度 200/200 用完** → 通知發不出是「額度」，不是斷線。bot 活著、客人 LINE 登入正常（登入不走額度）。

### D. 錢／收款問題
```
現金 → 後台標「已收現金」（無平台問題）
LINE Pay → ⏳ 未開通（等商家憑證）→ 目前現金/匯款
雷門 POS → 獨立系統，與網站不串
對帳：後台「今日總覽」已收款卡 vs 實際現金
```

### E. 硬體（穿線、販售櫃）
```
現場：Win10 kiosk ＋ RS-485 鎖控板 ＋ GoDex 印表機
現況：485 未通、列印未實測 → 現場另做（交接任務 #2）
應急：現場紙本＋人工開門（規格-販售與泡麵24h.md 第七節）；AnyDesk 遠端
```

### F. 資料怕丟
```
三層備份：GitHub（碼）＋ Neon PITR（資料，自動）＋ 每週日 pg_dump → iCloud（保留 8 份）
手動：雙擊 code/💾 備份Neon資料庫.command
確認：code/logs/launchd_neon_backup.log
```

## 三、平台「會用完/會過期」倒數清單
