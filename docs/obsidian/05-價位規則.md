# 價位規則（尖峰/離峰 + 假日 + 時長折扣）

## 三層定價

1. **特定日期**（`PriceRule` kind=date）：國定假日/颱風假，整日單一價，**優先**。
2. **固定週規則**（kind=weekly）：每週幾＋時段 → 價格。
3. **場地時價**（`Court.pricePerHour`）：無規則時回退。

## 現行規則（迪飛太平）

| 時段 | 價格 |
|------|------|
| 週一～五 08:00–17:00 | 離峰 **300** |
| 週一～五 17:00–24:00 | 尖峰 **400** |
| 週六 08:00–24:00 | 尖峰 **400** |
| 週日 08:00–20:00 | 尖峰 **400** |
| 週日 20:00–24:00 | 離峰 **300**（當時未指定，先設離峰） |

> 颱風假宣布時：後台「價位規則」加一筆「特定日期」即可整日調價。

## 時長折扣（第二層）

時段價算完後，再套「滿 N 分鐘折 X 元」：
- 例：尖峰 2 小時 800 − 滿 2 小時折 100（僅尖峰 400）＝ **700**。
- `DurationDiscount.tierPrice` 可限定「僅某時價」適用（null＝所有時段）。

## 計價單位

以 30 分鐘分段計價，跨尖峰/離峰的訂位自動分段算（如 17:30–18:30 = 離峰半小時＋尖峰半小時）。
