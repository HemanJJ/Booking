# 算帳與估價（合夥模式）

## 模式：A（合夥人，長期綁定）

- 不是收一筆開發費，而是**開發費＋維護費＋分潤**三層。

## 建議結構

| 項目 | 建議 |
|------|------|
| 前期開發費（象徵性） | NT$10–15 萬，分 3 期 |
| 每月維護＋授權＋雲端 | NT$1.5–3 萬/月 |
| 分潤 | 每家月營收 **3–5%**（或總營收 4–6%） |
| 或技術股（與分潤二選一） | 10–20% |

## 5 家分店（租拍系統）

- smartlocker 本就設計 5 家（df-a ~ df-e）。
- 已補「價格追蹤＋分店營收報表」，可分店算帳。
- 租拍預設租金 NT$50/次（待改實際價）。

## 換算範例

```
每店每天租 15 支 × NT$50 = NT$750/天
5 店 × 30 天 = 月營收約 NT$11 萬
抽 4% = 約 NT$4,400/月
```

（數字代入實際租金與出租率即可）

## 請款實務（台灣）

- 分期：簽約 30% → 上線 40% → 驗收 30%。
- 有公司行號 → 三聯式發票（＋5% 營業稅）。
- 個人 → 勞務報酬，次年申報綜所稅＋二代健保補充保費（2.11%）。
