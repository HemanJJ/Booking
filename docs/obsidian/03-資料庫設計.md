# 資料庫設計

完整定義在 `prisma/schema.prisma`（與 `prisma/schema.postgres.prisma` 同步）。

## 核心模型

| 模型 | 用途 | 關鍵欄位 |
|------|------|---------|
| `Member` | 會員 | `email`(唯一)、`passwordHash`、`lineUserId`(唯一)、`role`(member/admin) |
| `Venue` | 場館 | `name`、`openingTime/closingTime`、`status` |
| `Court` | 場地（每「面」場） | `venueId`、`name`、`pricePerHour`、`featured`(首頁精選)、`status` |
| `CourtImage` | 場地照片 | `courtId`、`url`、`sortOrder` |
| `CourtFacility` | 設施 | `courtId`、`name` |
| `PriceRule` | 價位規則 | `venueId`、`kind`(weekly/date)、`price`、`dayOfWeek`、`startTime/endTime`、`date` |
| `DurationDiscount` | 時長折扣 | `venueId`、`minMinutes`、`fixedAmount`、`tierPrice`(僅限某時價) |
| `Booking` | 訂位 | `courtId`、`memberId`、`date`、`startTime/endTime`、`durationMinutes`、`totalPrice`、`discountAmount`、`status` |
| `BookingSlot` | 訂位時段（防重疊） | `courtId`、`date`、`startTime`，`@@unique([courtId,date,startTime])` |

## 關係

```
Venue（場館）→ Court（場地）→ Booking（訂位）→ BookingSlot（時段格）
Venue → PriceRule / DurationDiscount
Member → Booking
```
