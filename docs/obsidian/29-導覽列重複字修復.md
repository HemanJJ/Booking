# 前台導覽列「重複字」修復（Tailwind sm:hidden 失效 → 原生 media query）

> 2026-09-03 修版上線。老闆看到導覽列印出「預約場館預約 / 場地查閱場地 / 訂位我的訂位」這種**重複字**。
> 本篇歸檔：症狀 → 根因 → 修法 → **多機協作的坑**（這次撞車的真正源頭）。

---

## 一、症狀

線上首頁導覽列（Header）出現重複字：

```
預約場館預約    場地查閱場地    訂位我的訂位    密碼修改密碼    後台管理後台
```

明明該顯示「場館預約 / 查閱場地 / 我的訂位」，卻把「手機 2 字 + 桌機 4 字」**兩個都印出來了**。

---

## 二、根因（主因）

舊版用 Tailwind responsive class 做「手機短 / 桌機長」切換：

```jsx
<span className="sm:hidden">預約</span>        {/* 手機(<sm)顯示 */}
<span className="hidden sm:inline">場館預約</span>  {/* 桌機(>=sm)顯示 */}
```

- `sm:hidden` / `hidden sm:inline` 是 **Tailwind 的響應式 class**。
- 但 **Tailwind v4 在部分瀏覽器/WebView 會整批不生效**（同 [[19-UI踩坑紀錄]] 的教訓）——
  media query 沒套上 → 兩個 span 同時可見 → 印出重複字。

> ⚠️ **通用教訓**：要「依螢幕寬度切換顯示」這類**功能性樣式，別依賴 Tailwind responsive class**；用**瀏覽器原生 `@media`**。

---

## 三、修法（已上線，0 改動之外還有高亮）

改 **`src/components/HeaderInner.tsx`**：加一段原生 `@media` 控制顯示。

```jsx
<style>{`
  @media (max-width: 639px) { .nav-full  { display: none; } }
  @media (min-width: 640px)  { .nav-short { display: none; } }
`}</style>
```

每顆導覽鈕改成雙 span：

```jsx
<Link href="/bookings/create" className={navCls(onBookingCreate)}>
  <span className="nav-short">預約</span>      {/* 手機(<640px)顯示 */}
  <span className="nav-full">場館預約</span>    {/* 桌機(>=640px)顯示 */}
</Link>
```

- **桌機（≥640px）**：顯示「場館預約 / 查閱場地 / 我的訂位 / 修改密碼 / 管理後台」（4 字全名）。
- **手機（<640px）**：顯示「預約 / 場地 / 訂位 / 密碼 / 後台」（2 字短標籤，好按）。
- 同時保留別人加的 `navCls()` **「當前頁面高亮」**（現在看哪就讓哪顆變綠）。

---

## 四、多機協作的坑（這次真正的源頭）

> ⚠️ **工作流程坑**，不是技術 bug。

- 我在自己機上改了 `HeaderInner.tsx` 要 push，但**被拒**：`remote contains work you do not have locally`。
- 原因：**另一台 Mac 也在同一 repo 改了 `HeaderInner.tsx`（加了 `navCls` 高亮）**，並且已 push 上 GitHub。
- 這正是 `AGENTS` 裡寫的「**多機共同開發規矩**」被違反：
  1. **改檔案前先 `git pull`**（另一台可能已改同檔）。
  2. push 被拒 → **先 `git rebase`**，不是硬 push。
  3. **勿同時改同一個檔案**（這次兩台都動了 `HeaderInner.tsx`，撞車）。

### 正確解法（已用）
```bash
git fetch origin
git rebase origin/main      # 把本地 commit 疊到 Remote 最新上面
# 若有衝突 → 手動解（本次：兩邊取「我的原生 media query」+「對方 navCls 高亮」）→ git add → git rebase --continue
git push origin main
./deploy.sh                 # 讓客人看到新版
```

> 下次動 `HeaderInner.tsx` 或任何多人共用的檔案，**先 `git pull` 再改**。
