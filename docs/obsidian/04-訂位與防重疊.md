# 訂位與防重疊（核心）

## 預約單位

- 以 **30 分鐘**為最小單位。
- 最短 30 分、最長 4 小時（後台/程式可調）。
- 一筆訂位佔用多個 30 分的 `BookingSlot`。

## 防重疊（資料庫層級保證）

`BookingSlot` 的 `@@unique([courtId, date, startTime])` 在**資料庫層級**保證：同一場地、同一天、同一時段**不可能被重複預訂**。

- 即便同時有兩筆請求競爭，其中一筆也會因唯一鍵違反（P2002）而整筆交易回滾。
- 不靠前端擋、不靠應用層檢查——靠資料庫唯一鍵，這是這類系統最關鍵、也最容易做錯的地方。

## 訂位流程

```
選場地 → 選日期 → 選開始時段 → 選時長 → 金額試算 → 送出
                                        ↓
                              建立 Booking + N 個 BookingSlot（transaction）
```

## 取消

取消時一併刪除對應 `BookingSlot`，釋放時段。

## 關鍵檔案

- `src/lib/booking.ts`：時段產生、建立/取消訂位、防重疊交易
- `src/lib/pricing.ts` / `pricing-core.ts`：分時計價
- `scripts/smoke.ts`：防重疊驗證腳本
