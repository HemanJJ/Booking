# 營運與維護（部署 / 角色 / 監控 / 故障排除）

> 給老闆（vibe coding）的維運總表。三個系統、怎麼部署、掛了怎麼查，都在這。
> 完整「護城河九件套＋地雷」清單見 `code/SKILL-系統維護護城河.md`。

## 三個系統一覽（雲端現況）

| 系統 | 程式位置 | 部署 | 線上網址 | 健康檢查 |
|------|---------|------|---------|---------|
| 球場 booking | `code/booking` | `./deploy.sh` | difly-booking.vercel.app | `/api/health` |
| 穿線 smartlocker | `code/smartlocker/web` | `./deploy.sh`（在 web/） | smartlocker-alpha.vercel.app | `/api/health` |
| 穿線 stringing | 住在 smartlocker 裡（共用站＋庫） | 同上 | 同上 | 同上 |

- 穿線（stringing）不是獨立系統，**共用 smartlocker 的 Vercel＋Neon＋LINE bot**；`code/stringing` 只是規格文件。
- 監控：兩個站都接 UptimeRobot（打各自的 `/api/health`，5 分鐘一次）。

## 一鍵部署（不用再 vercel login）

- 長期 token：兩個專案根目錄都有 `.vercel-token`（已 gitignore；booking 與 smartlocker/web 各一份）。
- token 失效：https://vercel.com/account/tokens → 重建 → 覆寫 `.vercel-token`。
- 部署：
  ```bash
  cd code/booking && ./deploy.sh
  cd code/smartlocker/web && ./deploy.sh
  ```
- 改「資料表欄位」不能只部署，還要 ALTER 到 Neon（見資料庫地雷）。

## Root Directory 地雷（smartlocker 已修 2026-08-20）

- **症狀**：`git push` 後 production 全站 404。
- **原因**：Next.js 程式在 `web/` 子目錄，但 Vercel 的 Root Directory 沒設 → 從 repo 根目錄 build 出空殼。
- **已修**：smartlocker 的 Root Directory 已設 `web`（透過 Vercel API，projectId `prj_0jkulSY9vd7vlPi8PmHGnG3KNHgd`）。
- **規則**：子目錄專案 push 後要驗證；404 → 立刻 `./deploy.sh` 恢復。
- booking 的 root 在根目錄，無此問題。

## 角色權限（booking，3 層）

| 角色 | 進後台 | 能做的事 |
|------|:---:|------|
| `member` 會員 | ❌ | 前台訂位、看自己訂位 |
| `staff` 員工 | ✅ 櫃台作業 | 儀表板、代客下單/改單/拖移、收款、固定訂位、批次匯入 |
| `admin` 館長 | ✅ 管理後台 | 全部（報表、價位、場館場地、會員、異動紀錄） |

- 開員工：後台 → 會員管理 → 「設為員工」。
- 敏感功能對員工**雙層鎖**：頁面導回 + server action 擋。

## 資料庫地雷（共用 Neon）

- 本地 SQLite；生產 **Neon 與租拍/穿線「共用同一個庫」**。
- ⚠️ **絕不跑 `npx prisma db push`**（會 drop 租拍/穿線的表）。
- 改 schema：本地 `prisma migrate dev`；生產用 `Pool` 跑「只 ADD COLUMN / CREATE TABLE」的 ALTER。

## 故障定位 SOP（3 層問法）

```
客人 → Vercel 網站 → Neon 資料庫  (+ LINE 平台，用到才查)
```

| 步 | 做 | 判讀 |
|----|----|------|
| ① | 開網站首頁 | 打不開 → Vercel（vercelstatus.com） |
| ② | 開 `/api/health` | 500 → Neon 掛；200 → DB 好 |
| ③ | 哪邊壞（前台/後台/LINE） | 對照速查表 |

- 線上壞、本地好 → 部署/環境變數問題（忘了 deploy 或漏設 env）。
- 本地也壞 → 程式 bug → 貼錯誤給 AI。
- 常用後台：Vercel、Neon、LINE Developers、LINE Official Manager。

## 故障排除速查

| 症狀 | 原因 | 解法 |
|------|------|------|
| `vercel --prod` 報 Not authorized | 短期 login token 過期 | 用 `./deploy.sh` |
| 後台 500 / 找不到欄位 | Neon 沒套新欄位 | 手動 ALTER |
| push 後全站 404 | Root Directory 空 | 設 `web`＋`./deploy.sh` 恢復 |
| LINE「預訂場地」跳首頁 | LIFF Endpoint 不是 `/liff` | 見 [[06-LINE整合]] |
| 圖文選單換圖 | API 建的 console 看不到 | `npx tsx scripts/richmenu.ts` |
| UptimeRobot 報 down、網站卻開得開 | 冷啟動＋北美節點誤報 | 別理，自動回 up |

## 每日例行（30 秒）

1. 開 booking 後台 `/admin` → 看四卡（今日訂位/收入/空場/未收款）→ 有數字＝活著。
2. 偶爾瞄「異動紀錄」確認無異常。
3. 收到 UptimeRobot down 信 → 先開網站確認，別急。
