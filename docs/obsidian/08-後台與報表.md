# 後台與報表

## 管理後台（`/admin`）

| 頁面 | 功能 |
|------|------|
| 儀表板 | 統計卡＋週表色塊＋最新訂位 |
| 報表 | 營收、訂位趨勢、場地使用率、時段熱門度 |
| 場館管理 | 新增/編輯/啟停（含營業時間） |
| 場地管理 | 新增/編輯/啟停（含「精選」首頁勾選） |
| 價位規則 | 尖峰/離峰週規則＋特定日期 |
| 時長折扣 | 滿 N 分鐘折 X 元 |
| 訂位管理 | 週表＋列表＋取消 |
| 會員管理 | 列表＋設為/取消管理員 |

## 週表（色塊）

- 列＝場地、欄＝未來 7 日。
- 顏色依「現行價位規則」重算：🔴尖峰(≥400) 🔵離峰(≤300) 🟡跨時段。
- 前台也有「查閱場地」供客人看占用（不顯示姓名）。

## 報表重點

- 營收：今日/近 7 天/近 30 天/累計。
- 訂位趨勢：近 14 天長條圖。
- 場地使用率：已訂時數＋營收排行。
- 時段熱門度：24 小時分布。
